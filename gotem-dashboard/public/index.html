Połącz z Shopify
Podaj adres swojego backendu na Vercel oraz domenę sklepu. Token jest bezpieczny — nigdy nie trafia do przeglądarki.
1
Wejdź na vercel.com → Twój projekt → Settings → Environment Variables
Dodaj: SHOPIFY_SHOP = gotem.myshopify.com i SHOPIFY_TOKEN = shpat_xxx
2
W Shopify: Settings → Apps → Develop apps → Create app
Scopes: read_products read_orders read_inventory → Install → skopiuj token
3
Wklej URL swojego projektu Vercel poniżej (np. https://gotem-dashboard.vercel.app)
